## Propósito del Repositorio
Este repositorio funciona como un manual de referencia técnica y guía operativa previa para las sesiones presenciales de laboratorio con la maqueta de multiplexación por división de longitud de onda densa (DWDM). La documentación abarca desde los principios teóricos y el reconocimiento del equipamiento físico (transpondedores, analizadores, fibra óptica), hasta los procedimientos de configuración, ruteo de cables y medidas de seguridad requeridas para garantizar un uso eficiente y profesional de los sistemas de transporte óptico de alta capacidad
